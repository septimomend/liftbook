# Liftbook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A home-screen web app (PWA) for iPhone that shows the owner's 7-day training program one exercise at a time, logs sets, runs a silent rest timer, lets the plan be edited, and backs up to Google Drive via the share sheet.

**Architecture:** Static site, no build step: vanilla JS ES modules + one CSS file under `app/`, served by GitHub Pages via an Actions workflow. All state lives on the phone in IndexedDB. The workbook is converted once by a Python script into `app/data/seed.json` + `app/img/*.jpg`, committed; the app copies the seed into IndexedDB only when IndexedDB is empty. Pure logic (model, timer, backup) is unit-tested with `node --test`; storage with `fake-indexeddb`; importer with `pytest` against the real workbook.

**Tech Stack:** HTML/CSS/JS (ES2022 modules, no framework), IndexedDB, Service Worker, Screen Wake Lock API, Web Share API; Node 24 `node:test` + `fake-indexeddb` (dev only); Python 3.12 + `openpyxl` + `Pillow` + `pytest` (importer only); GitHub Actions → GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-16-liftbook-design.md`

## Global Constraints

- App name: **Liftbook**. URL: `https://septimomend.github.io/liftbook/`. Repo: `septimomend/liftbook`, public. All in-app paths relative (`./…`) so the `/liftbook/` base works.
- Units: kg. Weights accept decimals; accept `,` as decimal separator.
- Defaults: target sets **3**, target reps **8–12**, rest **90 s** (1:30), rest adjust step **15 s**.
- Rest timer: **no sound, no vibration, no flash.** At zero show `Rest over · M:SS ago`, counting up. Timestamp-based (store end time in ms).
- Keep screen awake during an active workout (Wake Lock where supported; silently skip otherwise).
- Storage: IndexedDB only (no localStorage for data); call `navigator.storage.persist()` on start.
- Seed is written to IndexedDB **only when the store has no program**. App updates never overwrite the owner's edited program or logs.
- Backup = one JSON file `liftbook-backup-YYYY-MM-DD.json` shared via `navigator.share({files})`, fallback download. Restore replaces all local data after a confirm; lossless round-trip.
- No accounts, no network calls besides loading the site itself.
- Tap targets ≥ 44 px; ≤ 2 taps from opening the app to seeing the next exercise + weight.
- `gh` is logged in as `ichapk534_comcast`. Never create the repo or push until `gh auth status` shows `septimomend` active. Never ask for or handle a token.

## Review Focus

1. **App update after the owner has edited the plan** → edits and logs survive; seed not re-applied. Test in Task 3 (`bootstrap does not overwrite existing program`).
2. **Restoring a wrong file** (not JSON, other app's JSON, missing fields) → clear error, local data untouched. Test in Task 5 (`parseBackup rejects …`) and Task 3 (`replaceAll is atomic`).
3. **Phone locked through the end of rest** → on reopen shows correct `Rest over · X ago`, never negative/frozen. Test in Task 4 (`restView after end`) + `visibilitychange` re-render in Task 7.
4. **iOS keyboard comma decimals** (`"22,5"`) and empty input → parsed as 22.5 / rejected (Log disabled). Test in Task 1 (`parseWeight`).
5. **Swapping to an alternative that has no weight** → weight field empty, Log disabled until a weight is entered; editing weight there updates the alternative's weight, not the main exercise's. Test in Task 1 (`setWorkingWeight on alternative`).

## Data Shapes (shared by all tasks)

```js
// Program — stored under kv key "program"
{ version: 1, days: Day[] }
// Day
{ id: string, name: string, rest: boolean, exercises: Exercise[] }
// Exercise
{ id, group: string, name: string, type: "strength"|"cardio",
  weight: number|null, duration: string|null,      // duration only for cardio, e.g. "20-25 min"
  sets: number, repsMin: number, repsMax: number,
  image: string|null,                              // "img/<hash>.jpg" (bundled) or "idb:<id>" (user-added)
  alternatives: Alternative[] }
// Alternative
{ id, name: string, weight: number|null, image: string|null }
// Log — object store "logs", keyPath "id", indexes "exerciseId", "ts"
{ id, sessionId: string, ts: number /*ms*/, dayId, exerciseId, altId: string|null,
  name: string /*performed name at time of logging*/, set: number,
  weight: number|null, reps: number|null, done?: true /*cardio*/ }
// Settings — kv key "settings"
{ restSec: 90 }
// Session — kv key "session" (null when no workout in progress)
{ id, dayId, startedAt: number, index: number, swaps: { [exerciseId]: altId }, restEndsAt: number|null }
// Image — object store "images", keyPath "id"
{ id, type: string /*mime*/, blob: Blob }
```

Ids: `newId()` → `crypto.randomUUID()`.

### Task 2: Workbook importer → seed

**Files:**
- Create: `tools/import_workbook.py`, `tools/requirements.txt`, `tools/test_import_workbook.py`, `app/data/seed.json`, `app/img/*.jpg`

**Interfaces:**
- Produces: `app/data/seed.json` = `{ "version": 1, "days": Day[] }` per Data Shapes, with ids as stable slugs (`day-1`, `day-1-incline-barbell-press`, `…-alt-1`) and `image` as `"img/<sha1[:12]>.jpg"`.
- CLI: `python tools/import_workbook.py [--xlsx PATH] [--out app]`. Without `--xlsx` downloads `https://docs.google.com/spreadsheets/d/<SHEET_ID>/export?format=xlsx` to `tools/.cache/book.xlsx`.
- Python functions: `parse_workbook(path) -> dict` (no image writing), `extract_images(path) -> dict[(sheet_title, row1, col1), bytes]`, `main()`.

Parsing rules (spec "Source data"; verify against the file with openpyxl before coding):
- Sheets in workbook order → days `Day 1`…`Day 7`. A sheet whose A2 is `REST DAY` → `rest: true, exercises: []`.
- Skip row 1. For each row with a non-empty col B: group = col A if set else carried forward; name = col B; col C number → strength `weight`; col C string → cardio with `duration` = that string, `weight: null`.
- Remaining cells D… left to right: skip the literal `Alternative`; a string → new alternative; a number immediately after an alternative → that alternative's `weight`.
- All exercises get `sets 3, repsMin 8, repsMax 12` (cardio too; UI ignores them for cardio).
- Images: from `xl/drawings/drawingN.xml` (sheet→drawing via `xl/worksheets/_rels/sheetN.xml.rels`), anchor `xdr:from` row/col are **0-based** (add 1 for openpyxl). Assign each image to the name cell on the same row with the greatest column ≤ anchor column (main name in B, or an alternative's name). If none, print a warning naming sheet/row/col and skip.
- Images: Pillow, longest side ≤ 800 px, JPEG quality 80, RGB; filename `sha1(original bytes)[:12].jpg`, dedupe.

### Task 8b (new): Drive sync

**Files:** Create `app/js/config.js`, `app/js/auth.js`, `app/js/drive.js`, `app/js/sync.js`,
`tests/sync.test.js`, `docs/google-setup.md`. Modify `app/js/ui/settings.js`,
`app/js/ui/today.js`, `app/js/ui/workout.js` (Finish → sync), `app/js/main.js` (start-up sync).

**Interfaces:**
- `auth.js`: `getToken({ interactive: boolean }): Promise<string>` — cached in memory until
  1 min before expiry; non-interactive with no valid token rejects `Error("needs-sign-in")`;
  interactive calls GIS `requestAccessToken({ prompt: "" })` (must run from a tap).
  `signOut()`.
- `drive.js`: `makeDrive(getToken) → Drive` with
  `findOrCreateFolder(name): Promise<string>`, `findFile(folderId, name): Promise<{id}|null>`,
  `readText(fileId): Promise<string>`, `readBlob(fileId): Promise<Blob>`,
  `createFile(folderId, name, mime, body: string|Blob, appProperties?): Promise<string>`,
  `updateFile(fileId, body: string): Promise<void>`,
  `listImages(folderId): Promise<{fileId, imageId}[]>` — Drive REST v3 via `fetch`
  (`multipart` upload for create, `media` for update).
- `sync.js`:
  - `mergeState(local, remote)` pure → `{program, settings, logs, deletedLogIds}`: logs =
    union by id minus union of deletedLogIds; program/settings = higher `updatedAt` (tie →
    remote).
  - `syncOnce({ drive, store, now })` → `{ pulled: boolean, pushed: boolean }`:
    1. folder = meta.folderId ?? findOrCreateFolder("Liftbook"); file = findFile(folder, "liftbook-data.json").
    2. remote = file ? parse(readText) : null. merged = remote ? mergeState(local, remote) : local.
    3. `applyState(merged)` if it differs from local; write data file (create or update) if it differs from remote.
    4. Pictures: upload every local image whose id is not in `listImages`; download every
       `idb:` ref in merged program missing locally.
    5. saveSyncMeta({ ...meta, folderId, fileId, signedIn: true, lastSyncedAt: now }).
  - `syncNow({ interactive })` — glue: getToken → makeDrive → syncOnce; returns
    `{ ok: true } | { ok: false, reason: "needs-sign-in"|"offline"|"not-configured"|string }`.
- UI: Settings → "Google Drive" card: status (Not configured / Signed out / Last synced
  HH:MM), **Sync now** (interactive), Sign out. Today/start-up: if `meta.signedIn`, try
  non-interactive sync; on "needs-sign-in" show a slim banner "Tap to sync with Google
  Drive" that calls `syncNow({interactive:true})`. Finish workout triggers the same.
- `docs/google-setup.md`: numbered steps — create project, enable Google Drive API,
  OAuth consent screen (External, app name Liftbook, scope drive.file, **Publish to
  production**), create OAuth client "Web application" with Authorised JavaScript origin =
  deployed origin (+ `http://localhost:8080` for testing), copy client ID to the owner's
  reply.

**Tests (`tests/sync.test.js`, fake-indexeddb + in-memory FakeDrive implementing the Drive interface):**
